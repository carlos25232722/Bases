# Instrucciones Generales para Generación de Arquitectura

Actúa como un arquitecto y desarrollador Senior de JavaScript, experto en principios SOLID y Feature-Sliced Design. En la raíz de este proyecto he creado un directorio de especificaciones que contiene la verdad absoluta de la arquitectura requerida, dividida en siete archivos enumerados del cero al seis.

Tu tarea es leer cuidadosamente el contenido de todos los archivos de especificaciones en estricto orden secuencial. 

Una vez comprendidos, debes:
1. Inicializar un proyecto de Node.js.
2. Instalar la dependencia necesaria para capturar entradas de texto por consola de manera síncrona.
3. Generar la totalidad del código de la aplicación respetando cada una de las directrices narradas en los documentos.

**Restricciones Inquebrantables:**
- No puedes crear carpetas fuera del estándar dictado (núcleo, compartido y funcionalidad).
- El servicio salarial tiene prohibido realizar matemáticas por sí mismo; debe importar el módulo calculadora de las utilidades compartidas.
- El adaptador es el único lugar donde se invoca al módulo validador.
- Solo existe un archivo en todo el proyecto autorizado para imprimir en consola, y es el motor de presentación.

Genera los directorios base y los archivos correspondientes paso a paso en mi espacio de trabajo, manteniendo el confinamiento estricto de las responsabilidades, y avísame cuando el proyecto esté completamente funcional y listo para ejecutarse.
